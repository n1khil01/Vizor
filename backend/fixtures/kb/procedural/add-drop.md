# Add/Drop a Class

## Deadlines
The add/drop period runs through the first week of a full-length session (shorter for 7.5-week sessions — check the [Academic Calendar](https://students.asu.edu/academic-calendar)). Drops within this window leave no record on the transcript and are fully refunded; after it ends, a drop becomes a withdrawal (see the withdrawal entry) instead.

## Steps to add a class
1. On [My ASU](https://my.asu.edu), go to **My Classes** → **Add a Class**.
2. Search by course number or subject, and check the section has open seats and no unmet prerequisite or corequisite hold.
3. If a class is full, you can join the **waitlist** — you'll be auto-enrolled if a seat opens, as long as you have no schedule conflict at that time.
4. Review the updated schedule for time conflicts before confirming.

## Steps to drop a class
1. **My Classes** → select the class → **Drop**.
2. Confirm. If you're within the add/drop window, no W appears and tuition for that class is refunded.

## What people usually get stuck on
- A **prerequisite hold** on a course you've actually completed (e.g. transfer credit not yet posted) requires an advisor override — bring an unofficial transcript or AP/IB score report to the appointment, it goes faster.
- Waitlist auto-enrollment silently fails if it would drop you below full-time or create a time conflict — check your email confirmation, don't assume you're in.
- Dropping your **last class** in a term is a full withdrawal from the term, not a drop, and has separate financial aid and enrollment-verification consequences — talk to an advisor first.
