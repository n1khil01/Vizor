## Direction contract

THESIS: A rationed 3-color state grammar — maroon (needs the advisor), gold (student self-resolved), ink (advisor hard-resolved) — replaces the muted, decorative SaaS-dashboard palette, so a caseload reads at a glance instead of being guessed from a badge.

OWN-WORLD: Warm paper-white ground, visible baseline grid; ASU maroon #8C1D40 / gold #FFC627 / near-black ink as the only load-bearing colors, never decorative. One geometric sans for numerals/nav, a companion serif for reading-heavy content (DARS text, ticket bodies). Left icon-rail nav (Students / Tickets / Sessions / Reports); numbered ticket rows, never generic muted status pills.

STORY: Advisor signs in, reads caseload status at a glance, opens an escalated ticket, sees the student's real context (DARS + chat) already assembled, resolves it — the resolve action reads as visibly committed, not a soft toggle.

FIRST VIEWPORT: Left icon rail; a caseload status strip (each assigned student, one state dot); below it a numbered ticket queue, state-colored, student name plus one-line AI summary per row; the review action sits on the row itself.

FORM: Bauhaus foundation-workshop challenger, fused with the product and won on product clarity and audience identification (ASU-branded state law) against the assigned literal-SaaS-reference direction; seed key cfa49388.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
